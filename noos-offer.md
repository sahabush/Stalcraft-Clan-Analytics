# Публичная оферта на Noos Plus

Редакция от 19 ноября 2026 года.

## 1. Термины и стороны

1.1. SCWA — сервис Stalzone Clan Wars Analytics, доступный на [scwa.ru](https://scwa.ru). Noos — функция SCWA для автоматического разбора скриншотов Stalzone.

1.2. Исполнитель — самозанятый Останин Илья Алексеевич, ИНН 231522152178. Пользователь — лицо с учётной записью SCWA, принявшее условия оферты.

1.3. Noos Plus — услуга, которая включает возможность использовать API Noos и повышенный лимит новых разборов на сайте в течение 30 дней.

## 2. Предмет оферты и заключение договора

2.1. Исполнитель предлагает заключить договор оказания услуги на изложенных здесь условиях. Пользователь принимает оферту оплатой заказа. Договор заключается в момент подтверждения оплаты платёжной системой.

2.2. Бесплатный разбор на сайте доступен в пределах действующего бесплатного лимита. Для добровольной поддержки проекта действуют условия [оферты о пожертвовании](https://docs.scwa.ru/offer).

## 3. Стоимость, оплата и срок

3.1. Цена в рублях и действующие для заказа лимиты показаны [на странице тарифов](https://scwa.ru/noos/access) перед оплатой. Новая цена применяется к новым заказам. Оплата проходит через ЮKassa. Пользователь указывает адрес электронной почты для чека.

3.2. Срок доступа начинается с предоставления услуги после подтверждения оплаты. Дата окончания отображается в аккаунте. При ручном продлении действующего доступа 30 дней прибавляются к оставшемуся сроку. Автоматических списаний нет.

3.3. Пользователь выпускает ключ в своём аккаунте. Ключ можно заменить или отозвать. Пользователь отвечает за хранение ключа и может прекратить его действие при утрате контроля над ним.

## 4. Лимиты и результаты разбора

4.1. На новые разборы действуют скользящий минутный лимит API, суточный лимит API по UTC и скользящий часовой лимит на сайте. Для HTTP-запросов действует отдельное ограничение частоты. Время обработки зависит от типа изображения и очереди. При временной перегрузке сервис предлагает повторить запрос позже.

4.2. Результат автоматического распознавания может быть частичным или содержать ошибки. Точность распознавания не гарантируется. Проверяйте результаты перед использованием. Описание поддерживаемых файлов, результатов и статусов доступно в [документации API](https://scwa.ru/noos/docs).

## 5. Кадры, платёжные данные и обучение

5.1. Исполнитель обрабатывает кадры и результаты для предоставления разбора и доступа к нему. Платёжные сведения используются для учёта заказа, выдачи доступа, чека и рассмотрения обращений. Общие правила обработки данных и контакты для запросов указаны в [Политике конфиденциальности SCWA](https://docs.scwa.ru/privacy).

5.2. Передача кадров для обучения оформляется отдельно на сайте и добровольна. При обычном веб-разборе без такого действия и при загрузке через API кадры не передаются в обучающий набор. Удалить кадр API и его результат можно командой из документации API. Об удалении личных веб-разборов можно обратиться в поддержку.

## 6. Обращения и возвраты

6.1. По вопросам доступа, оплаты, чека, отказа от услуги или возврата можно обратиться через [поддержку SCWA](https://scwa.ru/support) или по электронной почте [support@scwa.ru](mailto:support@scwa.ru). Для поиска платежа укажите дату и сумму платежа, а при наличии — номер заказа.

6.2. Пользователь вправе отказаться от услуги в порядке, установленном законодательством Российской Федерации. При расчёте возврата применяются требования закона, включая правила о фактически понесённых расходах исполнителя по конкретному договору. Обращения рассматриваются в применимые по закону сроки.
